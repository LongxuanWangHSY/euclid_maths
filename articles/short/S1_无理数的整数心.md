# S1. 无理数的整数心：一个递推的故事

**本期定位**：日常短文 · 前置知识：一元二次方程、归纳法 · 时长：约 5 分钟

---

## 一题

> 设实数 $x$ 满足 $x + \dfrac{1}{x} = 3$。证明：对任意正整数 $n$，$x^n + \dfrac{1}{x^n}$ 都是整数。

先别急着算。$x = \dfrac{3 \pm \sqrt{5}}{2}$，两个无理数。我们的任务是证明：这两个"没道理"的数，任意次方的和，都恰好落回整数格点上。

---

## 一解

**先试几个。** 这是我们的老习惯——证明之前，先看结论长什么样。

$$x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2 = 3^2 - 2 = 7.$$

整数。

$$x^3 + \frac{1}{x^3} = \left(x + \frac{1}{x}\right)^3 - 3\left(x + \frac{1}{x}\right) = 27 - 9 = 18.$$

整数。

1、2、3 次都是整数。但"前三次是整数"和"任意次是整数"之间，隔着无限的距离。我们需要一座桥。

**关键观察——乘积展开。** 把相邻两档乘起来：

$$\left(x + \frac{1}{x}\right)\left(x^n + \frac{1}{x^n}\right) = x^{n+1} + \underbrace{x^{n-1} + \frac{1}{x^{n-1}}}_{\text{中间两项恰好配对}} + \frac{1}{x^{n+1}}$$

中间的 $x^{1-n} + x^{n-1}$ 整理后就是 $x^{n-1} + \dfrac{1}{x^{n-1}}$——比当前档**往回退两格**的那一项。

移项，得到：

$$x^{n+1} + \frac{1}{x^{n+1}} = 3\left(x^n + \frac{1}{x^n}\right) - \left(x^{n-1} + \frac{1}{x^{n-1}}\right)$$

**桥出现了。** 记 $a_n = x^n + \dfrac{1}{x^n}$，则

$$a_{n+1} = 3a_n - a_{n-1}.$$

已知 $a_1 = 3$，$a_2 = 7$。递推只做减法和乘法——整数减整数、整数乘整数，结果永远是整数。于是 $a_3$ 是整数，$a_4$ 是整数，一路推下去。归纳完成。∎

顺带一提，跑一下递推：$3, 7, 18, 47, 123, 322, 843, \dots$——如果熟悉斐波那契家族，你会认出它们是 **Lucas 数列** $L_1 = 1, L_2 = 3, L_{n+2} = L_{n+1} + L_n$ 的偶数下标项：$a_n = L_{2n}$。一个"无理数题目"的答案，落进了一个最著名的整数数列。

**再抬头看一眼。** 把 3 换成任意整数 $k$：$x + \dfrac{1}{x} = k$ 的两根依然是一对无理数，递推变成 $a_{n+1} = k a_n - a_{n-1}$，证明一字不改。这个"为什么换谁都可以"的答案，就藏在那两个"没道理的数"里——它们互为倒数，乘积恒为 $1$。这个不变式把整数性从 $n = 1$ 一路送到所有 $n$。真正撑起结论的从来不是 3，是对称本身。

---

## 一谈

$x = \dfrac{3+\sqrt{5}}{2}$ 和 $x = \dfrac{3-\sqrt{5}}{2}$，两个无理数，它们任何次方的和却都是整数。无理与有理之间本来隔着整条数轴，但这里有一条秘密通道——钥匙只有一把：递推。

我们常以为数学是堆出来的：学会一个，再学下一个。但真正的结构不是堆出来的，是**长**出来的——从 $n = 1$ 长出 $n = 2$，从 $n = 2$ 长出 $n = 3$。一个等式如果足够对称，它就自带楼梯：你只需要确认第一步站在了正确的地方，之后每一步，都自动踩实。先迈出第一步，剩下的，递推会接住你。
