# No11. 韦达定理：对称魔法的代数密码

> "There is no problem that cannot be solved by the proper arrangement of symbols."
> "没有什么问题是符号的恰当排列所不能解决的。" —— François Viète

任何一个学过初中数学的人都能脱口而出：对于二次方程 $x^2 + bx + c = 0$，如果它有两个根 $\alpha$ 和 $\beta$，那么

$$\alpha + \beta = -b,\quad \alpha\beta = c.$$

这是韦达定理（Vieta's formulas）最朴素的面孔。我们用它快速检验因式分解、心算两根之和而不必解出具体的根、或者在已知一根时顺手求出另一根。它是如此简洁好用，以至于很少有人追问一个更深层的问题：

**为什么系数恰好是根的和与积？这背后隐藏着什么结构？**

本文的答案只有一个词——**对称性**（symmetry）。韦达定理不是巧合，它是多项式根与系数之间对称关系的必然产物。理解了这一点，我们就能打开一扇通往代数深处的大门：从二次到 $n$ 次，从解方程到构造方程，从竞赛技巧到群论的前奏。

---

## 1. 破题分析：对称性从何而来

让我们回到二次情形，但这次不从"公式"出发，而是从"结构"出发。

考虑一个首一的二次多项式 $x^2 + bx + c$。如果它有两个根 $\alpha$ 和 $\beta$，那么根据因式定理，它必然可以分解为

$$x^2 + bx + c = (x - \alpha)(x - \beta).$$

把右边展开：

$$(x - \alpha)(x - \beta) = x^2 - (\alpha + \beta)x + \alpha\beta.$$

比较两边 $x$ 的同次幂系数，我们得到

$$\alpha + \beta = -b,\quad \alpha\beta = c.$$

就这么简单。但请停一下，注意到一件微妙的事：右边展开后，$\alpha$ 和 $\beta$ 是以**对称多项式**的形式出现的。交换 $\alpha$ 和 $\beta$，这两个表达式完全不变——$\alpha+\beta$ 交换后还是 $\beta+\alpha$，$\alpha\beta$ 交换后还是 $\beta\alpha$。

这不是偶然。左边 $x^2 + bx + c$ 的系数 $b$ 和 $c$ 并没有"偏向"哪一个根——系数只取决于多项式本身，而多项式不关心它的根被标上什么编号。所以系数必须是根的对称表达式。

这里有一个更深的观察，它将是全文的主线：

> **系数就是根的对称多项式。反过来，初等对称多项式恰好构成了所有对称多项式的"基本构件"——任何关于根的对称表达式，都可以用系数表示，而不需要解出根本身。**

这意味着什么？意味着一旦你知道 $\alpha + \beta$ 和 $\alpha\beta$，你就可以算出**任何**关于 $\alpha$ 和 $\beta$ 的对称表达式：

$$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = b^2 - 2c.$$

$$\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta) = -b^3 + 3bc.$$

$$\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta} = -\frac{b}{c}.$$

韦达定理的真正威力正在于此：它不是两个孤立的等式，而是一个完整的信息通道——系数告诉你关于根的一切对称信息，而根的对称信息反过来决定了系数。

## 2. 数学史插曲：密码、符号与对称性的发现

韦达定理的故事开始于一个与数学毫不相干的场景：16 世纪的法国宗教战争。

1590 年，法国国王亨利四世截获了大量西班牙军事密文，无人能破译。西班牙使用一种极其复杂的密码系统——据说包含超过 500 个字符——来加密通信。国王把密文送到了 François Viète（1540–1603）手中。

Viète 日夜伏案工作，最终成功破译了西班牙密码。西班牙人惊骇万分，甚至向教皇申诉，声称 Viète 使用了"巫术"。教皇的法庭经过调查后宣布：Viète 使用的不是巫术，而是数学。

这个故事之所以与韦达定理有关，是因为 Viète 破译密码的核心武器正是他刚刚发明的**符号代数**（symbolic algebra）。在他之前，代数是用文字描述的——"某数的立方加上某数的三倍等于二十"这种冗长的叙述方式。Viète 第一个系统地使用字母表示未知数和已知数，让代数表达式变得简洁、可操作、可变形。

韦达定理，正是符号代数威力的第一次华彩亮相。当 Viète 写下

$$x^n - \sigma_1 x^{n-1} + \sigma_2 x^{n-2} - \cdots + (-1)^n \sigma_n = (x - r_1)(x - r_2)\cdots(x - r_n)$$

并意识到 $\sigma_k$（初等对称多项式）恰好是各根之和、两两乘积之和、三三乘积之和……时，他实际上发现了一个贯穿整个代数史的秘密：**多项式的系数就是根的对称函数**。

一个破译密码的人，发现了代数方程中隐藏的"对称密码"。这个巧合，比任何小说都精彩。

## 3. 三次韦达：自己动手展开

理论不能只停留在二次。现在我们来挑战三次方程。

$$x^3 + px^2 + qx + r = 0,$$

它的三个根记为 $\alpha, \beta, \gamma$。和二次一样，有因式分解：

$$x^3 + px^2 + qx + r = (x - \alpha)(x - \beta)(x - \gamma).$$

我们亲手展开右边。先乘前两个：

$$(x - \alpha)(x - \beta) = x^2 - (\alpha + \beta)x + \alpha\beta.$$

再乘上第三个因子 $(x - \gamma)$：

$$\begin{aligned}
(x^2 - (\alpha + \beta)x + \alpha\beta)(x - \gamma)
&= x^3 - (\alpha + \beta + \gamma)x^2 \\[4pt]
&\quad + (\alpha\beta + \beta\gamma + \gamma\alpha)x \\[4pt]
&\quad - \alpha\beta\gamma.
\end{aligned}$$

比较系数，得到三次韦达定理：

$$\begin{aligned}
\alpha + \beta + \gamma &= -p, \\[4pt]
\alpha\beta + \beta\gamma + \gamma\alpha &= q, \\[4pt]
\alpha\beta\gamma &= -r.
\end{aligned}$$

符号规则简洁优雅：一次和取负，二次和（两两乘积之和）取正，三次和（三乘积）取负。这个正负交替的模式会一直延续到任意次。

现在观察对称性。这三个表达式——$\alpha + \beta + \gamma$、$\alpha\beta + \beta\gamma + \gamma\alpha$、$\alpha\beta\gamma$——在任意重排 $\alpha, \beta, \gamma$ 的顺序下都保持不变。我们可以用它们表示任何关于三根的对称表达式。例如：

$$\alpha^2 + \beta^2 + \gamma^2 = (\alpha + \beta + \gamma)^2 - 2(\alpha\beta + \beta\gamma + \gamma\alpha) = p^2 - 2q.$$

完全不需要解三次方程。对称性把我们从求解个别根的巨大计算量中解放了出来。

## 4. $n$ 次一般形式

推广到 $n$ 次首一多项式：

$$x^n + a_1 x^{n-1} + a_2 x^{n-2} + \cdots + a_n = (x - r_1)(x - r_2)\cdots(x - r_n).$$

展开右边并按 $x$ 的幂整理，得到韦达定理的一般形式：

$$a_k = (-1)^k \cdot \sigma_k(r_1, \ldots, r_n),$$

其中 $\sigma_k$ 是 $n$ 个根的 **$k$ 阶初等对称多项式**——即从 $n$ 个根中选出 $k$ 个相乘，再对所有这样的乘积求和。具体写出来：

$$\begin{aligned}
\sigma_1 &= r_1 + r_2 + \cdots + r_n, \\[4pt]
\sigma_2 &= r_1r_2 + r_1r_3 + \cdots + r_{n-1}r_n, \\[4pt]
\sigma_3 &= r_1r_2r_3 + r_1r_2r_4 + \cdots + r_{n-2}r_{n-1}r_n, \\[4pt]
&\;\;\vdots \\[4pt]
\sigma_n &= r_1 r_2 \cdots r_n.
\end{aligned}$$

公式本身已经足够清晰。关键是记住那个核心直觉：**系数就是对称多项式，对称多项式就是系数。** 这个双向等价，是韦达定理全部力量的来源。

## 5. 几何之眼：对称性在图形中显现

韦达定理本质上谈论的是对称性，而对称性最直接的载体是几何。让我们从二次出发，逐步上升到更一般的视角。

### 二次：抛物线的对称轴

考虑抛物线 $y = x^2 - (\alpha + \beta)x + \alpha\beta$，它与 $x$ 轴的两个交点就是 $\alpha$ 和 $\beta$。对称轴的位置恰好是

$$x = \frac{\alpha + \beta}{2}.$$

两根关于对称轴左右等距分布。而抛物线与 $y$ 轴的交点为 $(0, \alpha\beta)$。于是二次韦达定理的三个量各有一个几何角色：

- **$\alpha + \beta$**：决定对称轴——根的中心位置
- **$\alpha\beta$**：决定 $y$ 截距
- **$\Delta = (\alpha + \beta)^2 - 4\alpha\beta$**：决定两根之间的距离

### 三次：拐点即重心

上升到三次。考虑 $y = x^3 + px^2 + qx + r$，三个根 $\alpha, \beta, \gamma$ 是曲线与 $x$ 轴的交点。

三次曲线有一个著名的几何特性：它关于自己的**拐点**（inflection point）成中心对称。拐点在哪里？求二阶导数：

$$y'' = 6x + 2p = 0 \implies x = -\frac{p}{3}.$$

而由韦达定理，$p = -(\alpha + \beta + \gamma)$，所以拐点的 $x$ 坐标恰好是

$$x = \frac{\alpha + \beta + \gamma}{3}.$$

**三次韦达定理的 $\sigma_1$（三根之和）告诉我们拐点在哪——它是三根的算术平均。** 三根关于这个中心对称分布。如果我们将坐标平移，令 $x = t - p/3$，消去二次项得到降次三次方程（depressed cubic）$t^3 + Qt + R = 0$，此时三根之和为零——它们在新的坐标系下关于原点对称。消去 $x^{n-1}$ 项，等价于将根的"重心"平移到原点。

### $n$ 次：根的重心

推广到 $n$ 次，韦达定理的第一式是

$$\sigma_1 = r_1 + r_2 + \cdots + r_n = -a_1.$$

在复平面上，$\sigma_1/n$ 正是 $n$ 个根的**几何重心**。如果系数是实数，复数根成对出现（共轭对），每一对关于实轴对称，此时重心必然落在实轴上。

换句话说：**多项式的 $x^{n-1}$ 项系数决定了根的"集体位置"，而更高阶的对称多项式决定了根在重心周围的"散布形态"。** 韦达定理的对称性在几何上就是：无论你如何重排这些根，它们的重心不变，它们的各种高阶矩全都不变。

## 6. 应用武器库

理论讲完了。现在来看韦达定理到底能干什么。以下四个场景，从基本功到最高难度，覆盖了它最令人震撼的应用。每个场景配一道代表例题，按难度递进排列。

### 6.1 不解方程求对称式（启蒙）

> **题目**：已知方程 $x^2 - 5x + 3 = 0$ 的两根为 $\alpha, \beta$，求 $\alpha^4 + \beta^4$。

**分析**：按照常规思路，需要先用求根公式解出两根，再算四次方求和——这既繁琐又丑陋。用韦达定理，我们完全绕过求根步骤。识别信号：题目问的是两根的对称表达式，条件给的是系数。

**解答**：已知 $\alpha + \beta = 5$，$\alpha\beta = 3$。

$$\begin{aligned}
\alpha^2 + \beta^2 &= (\alpha + \beta)^2 - 2\alpha\beta = 25 - 6 = 19, \\[4pt]
\alpha^4 + \beta^4 &= (\alpha^2 + \beta^2)^2 - 2(\alpha\beta)^2 = 19^2 - 2 \cdot 9 = 361 - 18 = 343.
\end{aligned}$$

三步，心算即可。这就是对称多项式的威力——**每一个对称表达式都可以写成 $\sigma_k$ 的多项式，因此都可以用系数表达。**

一般地，$\alpha^n + \beta^n$（$n$ 次幂和，记为 $s_n$）有递推公式：

$$s_n = (\alpha + \beta)s_{n-1} - \alpha\beta \cdot s_{n-2},$$

其中 $s_0 = 2$，$s_1 = \alpha + \beta$。这个递推让我们对任意 $n$ 都能高效计算——它将通向 Newton 恒等式（§7）。

### 6.2 构造满足特定根的方程（进阶）

> **题目**：已知 $\alpha, \beta$ 是 $x^2 - px + q = 0$ 的两根。求以 $\alpha + \frac{1}{\beta}$ 和 $\beta + \frac{1}{\alpha}$ 为两根的二次方程，用 $p, q$ 表示。

**分析**：韦达定理可以双向使用——不仅可以从方程读根的信息，还可以从根的信息反写方程。识别信号：题目给定了原方程（即给定了根之间的关系），要求构造新方程（需要新两根之和与积）。

**解答**：已知 $\alpha + \beta = p$，$\alpha\beta = q$。新两根为

$$u = \alpha + \frac{1}{\beta} = \alpha + \frac{\alpha}{\alpha\beta} = \alpha + \frac{\alpha}{q} = \alpha\!\left(1 + \frac{1}{q}\right),$$

$$v = \beta + \frac{1}{\alpha} = \beta + \frac{\beta}{\alpha\beta} = \beta + \frac{\beta}{q} = \beta\!\left(1 + \frac{1}{q}\right).$$

新两根之和：

$$u + v = (\alpha + \beta)\!\left(1 + \frac{1}{q}\right) = p\!\left(1 + \frac{1}{q}\right) = \frac{p(q+1)}{q}.$$

新两根之积：

$$uv = \alpha\beta\!\left(1 + \frac{1}{q}\right)^2 = q\!\left(1 + \frac{1}{q}\right)^2 = \frac{(q+1)^2}{q}.$$

因此所求方程为

$$x^2 - \frac{p(q+1)}{q}x + \frac{(q+1)^2}{q} = 0,$$

或等价地乘以 $q$：

$$qx^2 - p(q+1)x + (q+1)^2 = 0.$$

**点评**：这道题的要点是——整个求解过程中我们从未解出 $\alpha$ 和 $\beta$ 的具体值。所有操作都在对称多项式的层面上完成。这正是韦达定理作为"信息通道"的威力：它可以双向传输，从方程到根，也从根到方程。

### 6.3 参数反推（进阶）

> **题目**：若方程 $x^2 - (k+2)x + (k^2 - 3k + 2) = 0$ 的两根互为倒数，求 $k$。

**分析**："两根互为倒数"是根之间的关系——$\alpha\beta = 1$。这也是一个对称条件，可以直接翻译为系数的方程。识别信号：题目给定了根之间的某种特殊关系（倒数、等差、等比、特定比例），要求反推参数。

**解答**：由韦达定理，$\alpha\beta = k^2 - 3k + 2$。两根互为倒数意味着 $\alpha\beta = 1$，因此

$$k^2 - 3k + 2 = 1 \implies k^2 - 3k + 1 = 0 \implies k = \frac{3 \pm \sqrt{5}}{2}.$$

还需验证判别式非负，确保两根是实数。判别式 $\Delta = (k+2)^2 - 4(k^2 - 3k + 2)$。代入两个 $k$ 值验算，两者均满足 $\Delta \geq 0$，因此两个解都有效。

**点评**：这类问题的本质是——根之间的关系通过韦达定理转化为系数之间的方程。韦达定理在这里扮演的是一个**翻译器**：将根的语言翻译成系数的语言，反之亦然。

### 6.4 Vieta Jumping：IMO 1988 的传奇（拔高）

现在我们来到全文的最高潮。1988 年的国际数学奥林匹克（IMO）第 6 题，被公认为竞赛史上最难的题目之一。

> **IMO 1988 / 问题 6**：设 $a$ 和 $b$ 是正整数，且 $ab + 1$ 整除 $a^2 + b^2$。证明：
> $$\frac{a^2 + b^2}{ab + 1}$$
> 是一个完全平方数。

这道题难到什么程度？IMO 的六位命题委员——包括澳大利亚数论专家——在给出这道题时，自己也无法在限时内做出。满分 7 分的题目，参赛的 268 名选手中仅有 11 人得到满分。但这道题也催生了数学竞赛史上最精彩的技巧之一——**韦达跳跃**（Vieta jumping）。

**证明**：设 $\displaystyle k = \frac{a^2 + b^2}{ab + 1}$，其中 $k$ 是正整数。我们要证明 $k$ 是完全平方数。

固定 $k$，考虑所有满足条件的有序正整数对 $(a, b)$。由对称性，不妨假设 $a \geq b$。

改写等式：

$$a^2 + b^2 = k(ab + 1) \implies a^2 - kb\,a + (b^2 - k) = 0.$$

这是关键一步——我们把等式重排为关于 $a$ 的二次方程：

$$a^2 - (kb)a + (b^2 - k) = 0.$$

这是一个以 $a$ 为变量、$b$ 和 $k$ 为参数的二次方程。由韦达定理：

- 两根之和：$a + a' = kb$
- 两根之积：$a \cdot a' = b^2 - k$

我们知道其中一根就是 $a$ 本身。另一根记为 $a'$，由韦达定理：

$$a' = kb - a.$$

因为 $k$、$b$、$a$ 都是整数，所以 $a'$ 也是整数。而且

$$a' = \frac{b^2 - k}{a}.$$

现在来看 $a'$ 的正负。如果 $a' < 0$，则 $a' \leq -1$，于是

$$b^2 - k = a a' \leq -a \implies k \geq b^2 + a.$$

但由 $k = \frac{a^2 + b^2}{ab + 1}$ 和 $a \geq b$ 可以证明 $k < \frac{a^2 + b^2}{ab} \leq \frac{a}{b} + \frac{b}{a} \leq a + 1$，这与 $k \geq b^2 + a$ 矛盾（当 $a, b$ 足够大时）。因此 $a' \geq 0$。

如果 $a' = 0$，则 $b^2 - k = 0 \implies k = b^2$——正是完全平方数，得证。

如果 $a' > 0$，那么 $(a', b)$ 是另一个满足条件的正整数对。而且

$$a' = \frac{b^2 - k}{a} < \frac{b^2}{a} \leq \frac{a^2}{a} = a,$$

所以 $a' < a$——新得到的 $a'$ 比原来的 $a$ 更小。

这就是"跳跃"部分：**从一个解"跳"到另一个更小的解。** 如果 $a' > 0$ 且 $a'$ 仍然不满足完全平方条件，我们可以以 $(a', b)$ 作为新的起点，再次应用韦达定理，得到一个更小的 $a''$。这个下降过程必然终止——因为正整数不能无限变小。终止的唯一可能是某一步产生 $a^{(n)} = 0$，此时 $b^2 = k$，$k$ 是完全平方数。

---

**证明背后的深层结构**。

请停一下，往回看整个证明的逻辑骨架。你会发现它和反证法有一个微妙的区别——这个证明不是在说"假设不存在 → 推出矛盾"，而是在说：

> 假设存在反例（$k$ 不是完全平方数）。取 $a$ 最小的那个反例。用韦达定理造一个更小的反例。矛盾——因为最小的不能再小。

这是**无穷递降法**（Method of Infinite Descent）的经典三段式。Vieta jumping 不过是无穷递降法在二次方程场景下的一个精妙实现——韦达定理扮演了"下降引擎"的角色，从方程的一个根算出另一根，而另一根恰好更小。

这正是下一期 No12 的主题。我们将从 Fermat 证明 $x^4 + y^4 = z^4$ 无正整数解开始，系统展开无穷递降法的五种模式——反证递降、递降到平凡基 case、递降 + 回溯 = 完全分类、图论中的最小度贪心、以及你刚刚见证的 Vieta jumping。五种模式共享同一个逻辑地基：良序原理——正整数不能无限严格递减。

## 7. 轻触远方

韦达定理是冰山一角。在水面之下，有两个方向值得读者知道它们的存在。

**Newton 恒等式**（Newton's identities）刻画了 $n$ 次幂和 $s_k = r_1^k + \cdots + r_n^k$ 与初等对称多项式 $\sigma_k$ 之间的递推关系。§6.1 中的递推公式 $s_n = \sigma_1 s_{n-1} - \sigma_2 s_{n-2}$（对二次情形）就是它的特例。Newton 恒等式告诉我们：**所有对称多项式都可以用初等对称多项式表示**——这是对称多项式基本定理的量化版本。

再往深处走，**Galois 理论**的核心洞察是：一个多项式的 Galois 群定义为所有保持根之间代数关系不变的置换——也就是说，**一个置换属于 Galois 群，当且仅当它保持所有以根为变量的对称多项式不变。** 韦达定理中系数与对称多项式之间的对应，为理解"为什么五次及以上方程没有根式解"提供了第一个线索。

从韦达定理到 Newton 恒等式，再到 Galois 理论——这是一条完整的上升路径。读者不必现在就走完它，但知道这条路存在，本身就是一种方向感。

## 8. 教学研究后记

韦达定理在中学课堂里通常被压缩成一个"知识点"：两根之和等于 $-b/a$，两根之积等于 $c/a$。记住，套用，下一章。

这种教法最大的损失不是少讲了什么，而是把对称性这个灵魂埋没了。学生学到的是两个孤立的公式，而不是一个贯穿代数史的思维方式：**在看似混乱的变化中找到那个不变的东西。**

这正是 Viète 在 1590 年破译西班牙密码时做的事。面对一堆看似毫无规律的密文，他没有猜测，没有巫术，而是一件事——寻找对称性。他发现密码中某些字符组合总是以固定的模式出现——那就是密码结构的对称不变量，就像多项式系数在根的任意置换下保持不变。

400 多年后，当一个学生用韦达定理从方程系数推知两根平方和、用 Vieta jumping 在 IMO 考场"跳跃"时，他做的正是同一件事。

> 理解对称，就理解了代数中最深的力量。
