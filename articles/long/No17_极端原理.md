# No17. 极端原理：从最大最小处破局

> "The whole is greater than the part."「整体大于部分。」—— Euclid, *Elements*, Common Notion 5

## 一、引子：一个几乎不用证明的事实

对任意 $n$ 个实数 $a_1, \dots, a_n$，记均值 $\bar a = \dfrac{1}{n}\sum a_i$，则

$$\max_i a_i \ge \bar a \ge \min_i a_i.$$

最大值不小于平均值，最小值不大于平均值——这句"废话"就是极端原理的种子。把它用到极致，便得到整套方法：**当题目要求证明"必存在某某"或"必不可能某某"时，与其在茫茫对象中寻找线索，不如直接抓住最极端的那一个——最大、最小、最远、最近——极端元素受约束最强，最强的约束最容易逼出结论。**

这个直觉可以形式化为三个论证模板，下面逐一展开。

## 二、原理的形式化

**良序原理（Well-ordering Principle）**：$\mathbb{N}$ 的任意非空子集必有最小元；有限实数集合必有最大元与最小元。

这是极端原理的逻辑地基，我们不作证明，只把它当作一条公理。由它立即得到极端原理的**三个论证模板**：

- **模板 A（平均极值）**：对若干数，$\max \ge \bar a \ge \min$，直接锁定极值的存在与下界。
- **模板 B（最小反例）**：反设结论不成立，取**最小的反例**；在它身上推出矛盾（通常是通过它构造出更小的反例）。凡"证明不存在"的题目，都可尝试此模板。
- **模板 C（极值性质）**：极值对象本身带有强性质，常能反推出整个系统的结构。

下面三个应用分别对应三个模板，难度逐层上升：**基础 → 进阶 → 拔高**。

## 三、应用一（模板 A · 基础）：平均极值

### 例 1：三角形中必有不小于 60° 的角

**命题**：任意三角形 $ABC$，$\angle A, \angle B, \angle C$ 中至少有一个不小于 $60°$，也至少有一个不大于 $60°$。

**分析**：拿到"至少有一个角 ≥ 某值"的题，先问：这个"某值"从哪来？三个角的和是定值 $180°$，定值均分给三个角，每份恰是 $60°$——"60°"不是凭空出现的，它就是平均值。而"至少有一个 ≥ 平均值"是必然的：若每个角都 < 平均值，三个角的和就 < $180°$，矛盾。这就是模板 A 的思路源头：**先算平均值，再问极值**。

**证明**：$\angle A + \angle B + \angle C = 180°$，故三角之均值 $\bar a = 60°$。由 $\max \ge \bar a$，最大的角 $\ge 60°$；由 $\min \le \bar a$，最小的角 $\le 60°$。∎

注意证明中完全不涉及三角形的具体形状——极端原理对任何一组可以取均值的数都有效。同时它展示了模板 A 的常态：**一次论证，锁定两个方向**。

### 例 2：圆周被 n 个点分成的弧段

**命题**：在圆周上任意取 $n$ 个点，它们把圆周分成 $n$ 段弧，则至少有一段弧的长度不小于 $\dfrac{360°}{n}$。

**分析**：与例 1 同构——"必有一段 ≥ 某值"，某值仍是平均值：各段弧长总和是定值 $360°$，均分给 $n$ 段，每份 $\dfrac{360°}{n}$。题面一变（分数→角→弧），骨架没变（总量定值 → 均值 → 极值）。这正是极端原理值得反复练的原因：**识别"总量定值"是模板 A 的开关**。

**证明**：各段弧的长度和为 $360°$，均值恰为 $\dfrac{360°}{n}$。由 $\max \ge \bar a$，最长的一段弧 $\ge \dfrac{360°}{n}$。∎

从"全班分数"到"三角形角"再到"圆周弧段"，模板 A 一以贯之：**只要有一组数、有一个总量，极值就能逼出"必存在"**。

## 四、应用二（模板 B · 进阶）：最小反例

### 例 1：分数必可化为既约分数

**命题**：对任意正整数 $a, b$，存在互素的整数 $p, q$（$q > 0$）使得 $\dfrac{a}{b} = \dfrac{p}{q}$。

**分析**：题目要证"存在互素表示"，等价于说"最简分数存在"。怎么找它？茫茫多表示里，**分母最小的那个**最接近"最简"——它是极值，极值若还带公因子，就能约得更小，与极值矛盾。这里"取最小分母"是自然的一跃：良序原理保证最小值存在，我们要做的只是**检查极值处会发生什么**——这就是模板 B 的思维起点。

**证明**：在所有表示 $\dfrac{a}{b}$ 的分数中，分母取最小值，设最小者为 $q_0$，对应分子 $p_0$。（分母构成 $\mathbb{N}$ 的非空子集，由良序原理，这样的 $q_0$ 存在。）若 $\gcd(p_0, q_0) = d > 1$，则 $\dfrac{p_0/d}{q_0/d}$ 仍是 $\dfrac{a}{b}$ 的表示，而 $q_0/d < q_0$，与 $q_0$ 最小矛盾。故 $\gcd(p_0, q_0) = 1$。∎

**注意这里"取最小"的合法性**：正是良序原理保证了"最小的那个"一定存在。这是极端原理屡试不爽的前提——题目中的对象必须是"能取到极值"的。

### 例 2：质因数分解的存在性

**命题**：任意整数 $n \ge 2$ 可以分解为有限个素数之积。

**分析**：要证"都能分解"，反过来说就是"不存在不能分解的数"。对"不存在"类的命题，模板 B 的起手式是：反设存在，**取最小的那个**，看它身上能否造出矛盾。最小的不能分解数 $m$ 非素数，必可拆成两个更小的因子——而更小的数都能分解（最小性），拼起来 $m$ 就能分解了。矛盾来自"最小反例自己拆自己"。

**证明**：反设存在不能分解的数，取最小的一个，记为 $m$。$m$ 非素数（否则自身即分解），故 $m = m_1 m_2$，其中 $2 \le m_1, m_2 < m$。由 $m$ 的最小性，$m_1, m_2$ 均可分解，合起来即 $m$ 的分解，矛盾。故不存在不能分解的数。∎

### 例 3：调和和数不是整数

**命题**：对任意 $n \ge 2$，$H_n = 1 + \dfrac{1}{2} + \dfrac{1}{3} + \cdots + \dfrac{1}{n}$ 不是整数。

**分析**：前两例的"极端"都在"最小"；这一例换一种极端——**最特殊的项**。$H_n$ 通分后要判断"是否为整数"，关键看分母里 2 的最高次幂：$1$ 到 $n$ 里，$2^k$（$2^k \le n < 2^{k+1}$）是唯一一个含 $k$ 个因子 2 的数，其余数含的 2 都更少。通分时这项的分子保持奇数，其余全是偶数——**全式只有这一个"极端项"是奇数**，总和必为奇数，与整数矛盾。这里的"极端"不是最大最小，而是"最特别的那个"——极端原理的变体。

**证明**：反设 $H_n = M \in \mathbb{Z}$。取 $k$ 为满足 $2^k \le n$ 的最大整数（$k \ge 1$），令 $L = \text{lcm}(1, 2, \dots, n)$，则 $v_2(L) = k$。两边乘以 $L$：

$$L \cdot H_n = \sum_{i=1}^{n} \frac{L}{i} = LM.$$

对 $i \neq 2^k$：$i \le n < 2^{k+1}$，故 $i$ 中因子 2 的个数 $\le k-1$，于是 $L/i$ 是偶数。对 $i = 2^k$：$L/2^k$ 是奇数。故 $\sum L/i$ 为偶数之和 + 奇数 $=$ 奇数；而 $LM$ 为偶数（$L$ 含因子 2）。奇数 ≠ 偶数，矛盾。故 $H_n$ 不是整数。∎

注意例 3 与例 1、2 的骨架完全一致：**反设 → 取最小（或最特别）→ 在它身上造出矛盾**。

## 五、应用三（模板 C · 拔高）：极值性质

### 例 1：支撑直线

**命题**：平面上任意有限点集，存在一条直线过其中一点，使得所有点都在该直线的同侧（含线上）。

**分析**：要证"存在一条支撑线"，先想：什么样的点最可能"撑住"整个点集？——**最高（或最低）的那个点**。它已经是极值，没有任何点比它更高，于是过它的水平线天然就是支撑线。这是模板 C 的最小例子：**极值对象自动带出全局性质**，不需要任何构造。

**证明**：取所有点中 $y$ 坐标最大者 $P$，过 $P$ 作水平直线 $l$。由 $P$ 的取法，所有点的 $y$ 坐标 $\le P$ 的 $y$ 坐标，故所有点都在 $l$ 上或其下方。∎

看似平凡的观察，正是凸包理论的起点——凸包的所有顶点，都是某个方向上的"极端点"。

### 例 2：最长路径一定带出圈

**命题**：若一个图有有限个顶点，且每个顶点的度数至少为 2，则图中必存在一个圈。

**分析**：要证"必有圈"，直接找一个圈很难。换个思路——取一个极值对象：**最长的一条路径**。它的极值性质是：这条路已经走到头了，端点想再走一步，只能"回头"——而一回头，圈就出现了。这就是模板 C：极值对象自己把结构暴露出来。

**证明**：设 $v_1 v_2 \cdots v_k$ 是一条最长路径（不能再延伸）。端点 $v_1$ 的度数至少为 2，所以除 $v_2$ 外它还有至少一个邻居 $v_i$。若 $v_i$ 不在路径上，则路径可以延伸到 $v_i$，与"最长"矛盾；故 $v_i$ 必在路径上（$i \ge 3$）。于是 $v_1 v_2 \cdots v_i v_1$ 就是一个圈。∎

极值对象（最长路径）走不动了，只能回头成圈——这正是模板 C 的教科书示范。这个例子也顺便和图论（No18）接上了：图里度数全 $\ge 2$ 必有圈，是一笔画之外图论的又一则核心事实。

## 六、启发与一般化

三个应用，从小学几何到初中竞赛，表面题材迥异，骨子里是同一套论证：

$$\text{极值存在（良序原理）} \;\Rightarrow\; \text{抓住极值对象} \;\Rightarrow\; \text{极值处的强约束逼出结论}.$$

**为什么极端原理合法？** 因为它唯一的非平凡前提——"极值一定存在"——由良序原理保证。凡题目中的对象是自然数、或有限集合，取最大最小**永远合法**。这是极端原理与那些"灵光一现"技巧的根本区别：它有坚实的逻辑地基，是*可复制*的思考习惯，而非*一次性*的灵感。

**与 No12 无穷递降法的关系**：递降法从任意反例出发，构造更小的反例，形成无穷下降链——它证明"反例不存在"用的是**链条**；极端原理直接跳到链条底部，审判**最小反例本身**。二者实质相通（递降每一步的收敛都靠良序性），但战术不同：递降是动态的、构造性的，极端是静态的、一次性的。遇到"证明必然/不可能"的题目，两条路都在手边。

**操作建议**：拿到一道以"任意""必存在""不可能"开头的题，先问三个问题——
1. 这组对象是自然数或有限集吗？（决定能否取极值）
2. 若要证存在，哪个极值（最大/最小/最远）会带出结论？（模板 A、C）
3. 若要证不存在，能否反设并取最小反例？（模板 B）

**识别信号速查**：

| 看到什么 | 想到什么 |
|---------|---------|
| "必存在一个 ≥ / ≤ 某数" | 模板 A：总数 ÷ 个数 |
| "不可能存在" | 模板 B：反设最小反例 |
| "最远/最高/最大" | 模板 C：极值对象带全局性质 |
| 对象是自然数 / 有限集 | 良序原理：极值必存在，大胆取 |

## 七、教学研究后记

为什么"任意……必存在……"的题，学生普遍觉得难？因为**没有抓手**。知识点都学过，但题目不指向任何一条路——茫茫对象，从哪下手？

极端原理的价值，正在于它是第一个可以教的抓手：**先问"哪个最极端"**。它不是灵光一现的技巧，而是每次都可以先试试的第一步。教学时不妨先让学生撞一次墙——一道"任意 n+1 个不超过 2n 的正整数中必有两个互质"的题，让他们自己枚举、构造、卡住；卡住之后，"取最小的那个"才会真的落到心里。另外有两个小坑值得专门敲打：一是取极值必须确认对象是自然数或有限集（对无限对象随手取最小是错的）；二是最小反例的构造必须真的更小、且真的是反例。

更深的道理藏在三个例子里：**极端处最诚实。** 一个系统的性质，往往在它的极端处暴露得最清楚——最大的角、最小的分母、最边上的蚂蚁。认识一个集合，先看它的边缘。这个习惯，数学里叫极端原理，生活里叫"看问题要看到底"。它与 No12 无穷递降法是一对姊妹——递降是"走楼梯"，极端是"坐电梯"；两课并授，学生往往自己就能发现"递降的终点就是极端"。

## 八、数学史小记

（本节与正文解耦，简述这一方法的历史。）

"自然数非空子集必有最小元"这一良序思想，欧几里得在《几何原本》辗转相除中已暗中使用——每一步余数严格递减，**递减必须终止**，正是良序性的雏形。Fermat 把它铸成武器：无穷递降法在数论中战功赫赫，其核心正是"取最小反例"。20 世纪 Erdős 将"最大最小"发展为极值组合学这一整片学科。从 Euclid 的种子到 Erdős 的森林，"抓极端"走了两千多年——它提醒我们：再平凡的直觉，用得足够彻底，也能成为撬动整个领域的那根杠杆。

## 思考题

**问题 1（★★★☆☆，模板 A 升级）**：圆周被 $n$ 个点分成 $n$ 段弧，证明：总存在两段**相邻**的弧，它们的长度之和不大于 $\dfrac{720°}{n}$。（提示：设各段弧长为 $a_1, \dots, a_n$，考虑 $n$ 个"相邻和" $a_i + a_{i+1}$（视 $a_{n+1} = a_1$），这些相邻和的总和是多少？）

**问题 2（★★★☆☆，模板 B，与 No14 §2.1 对照）**：证明：任何正整数都可以写成若干个**互不相同**的 2 的幂之和。（提示：反设存在最小的不能表示的数 $m$；取最大的 $2^k \le m$。若 $m = 2^k$ 已得证，否则看 $r = m - 2^k$——注意 $r < m$ 且 $r < 2^k$，后者保证 $r$ 的任何表示都不会含 $2^k$ 或更大的项。同一结论在 No14 §2.1 用归纳构造证明过——对比两种证法，感受"构造"与"取极值"的分工。）

**问题 3（★★★★☆，模板 B 压轴）**：证明：任意整数 $n \ge 2$ 的质因数分解是**唯一**的（不计顺序）。（提示：先记住数论最基本的事实——**Euclid 引理**：若素数 $p$ 整除 $ab$，则 $p$ 整除 $a$ 或 $b$。反设 $n$ 是最小的能分解成两种不同方式 $p_1 \cdots p_r = q_1 \cdots q_s$ 的数，用 Euclid 引理说明 $p_1$ 必等于某个 $q_j$；两边约去 $p_1$，得到一个更小的、同样有两种分解的数，与 $n$ 的最小性矛盾。注意：若 $n$ 是素数，分解只有一种，不构成反例。）
