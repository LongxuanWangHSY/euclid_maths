## 这是什么

一个真实运营中的数学公众号的完整内容仓库：

- **22 篇长文**（No 系列）：一个专题讲透，从破题到一般化，篇幅数千字
- **8 篇日常短文**（S 系列）：一题一解一谈，五分钟读完
- **特辑与公告**：高考祝福合集、勘误致歉等
- **七个自有写作技能** + 一个第三方技能（`humanizer-zh`）：支撑上述产出的工作流

它不是一个"prompt 合集"。它是一套**已经跑了大半年、产出 30+ 篇文章、并且被读者挑过错**的完整内容生产流程——包括那套流程里的门控、规范、审阅机制，以及从真实事故中提炼的核查清单。

> **勘误也是资产。** 仓库里有一份[致歉公告](articles/other/公告_关于极端原理一处错误的致歉.md)——一篇文章写入过错误的几何命题，被读者发现后公开更正。这件事直接催生了工作流里的「命题正确性核查」硬规则：所有命题发布前必须构造反例验证。**这套流程的价值有一部分正来自它踩过的坑。**

## 写作工作流

位置：`.claude/skills/`。形式是 [Claude Code](https://claude.com/claude-code) 的 skill 定义（`SKILL.md`），核心是一套写给 AI 的执行规范。

### 两阶段门控

整套流程最值得看的设计——**创意与执行被一道硬门控隔开**：

```
第一阶段：规划（最大化创意）
  确认文章结构 → 板块轮换检查 → 轨道确认 → 头脑风暴（多方案并行）
        ↓
   ⛔ 门控点：必须等用户明确批准
        ↓
第二阶段：执行（严格对齐规划）
  按批准的规划写作，不得擅自增删板块、更换叙事线
```

门控前允许越界创新，门控后禁止任何未经批准的创意。**这解决了 AI 写作最典型的失败模式**：一边写一边"优化"，最后写出一篇没人批准过的东西。

### 七个自有技能

| 技能 | 作用 |
|---|---|
| `euclids-gate-math-writing` | **写作引擎**：精神纲领、写作宗旨、四类文章模板、语言规范、教学法规范六条 |
| `euclids-gate-figure` | **配图引擎**：图型路由、TikZ / pgfplots 编译管线、出图质检纪律 |
| `euclids-gate-writing-interaction` | **交互协议**：两阶段门控、选题候选制、四条交互原则 |
| `euclids-gate-manage` | 文章索引读写、文件保存、版本备份规则 |
| `euclids-gate-agenda` | 跨会话任务追踪（未完成的思考题、待写专题） |
| `euclids-gate-teacher-review` | **教师视角审阅**：模拟一线资深教师的课堂可用性检查 |
| `euclids-gate-student-review` | **学生视角审阅**：模拟重点中学学生的真实阅读体验 |

另有第三方技能 `humanizer-zh`（去除 AI 写作痕迹，见其 LICENSE）。

### 三处特别值得借鉴的设计

**1. 教学法规范：把"好教学"写成可执行的六条**

不是抽象的教育理念，而是可检查的动作要求：

- **变式练习**：每篇至少一个"把已讲方法应用到变更条件"的题，并说明「变了什么／为什么这样变／结论如何变」
- **元认知展示**：破题分析要展示一次**真实的思维挣扎**（"我先试了 X，为什么不行；于是试 Y"）——真实挣扎比完美重构更有教学价值
- **设问留白**：修辞性设问后禁止立即自答，要给读者思考间隙
- **金句节制**：单篇升华金句 ≤1 处，结尾优先用具体叙事收束而非抽象格言
- **名言去重**：同一名言跨篇复用间隔 ≥5 篇，避免名句库存化
- **认知负荷路标**：长文加结构预告与每节要点

**2. 双视角审阅：让 AI 分别扮演老师和学生**

写完后可以分别加载两个审阅技能，从两种立场挑毛病：

- **教师视角**：这篇能直接进课堂吗？哪里学生会卡住？例题梯度合理吗？
- **学生视角**：我愿意读完吗？哪里我看不懂？会不会觉得被说教？

关键在于**这两个视角都不参与写作阶段，只在写完后按需加载**——避免写作时向读者口味妥协，流失深度与立意。

**3. 配图引擎：数学内容必须有图，且图必须被核查**

`euclids-gate-figure` 提供图型路由（几何/组合→TikZ，函数图像→pgfplots，知识地图→draw.io）、编译管线，以及一套**出图质检纪律**：两轮九区盘点、红队复审、交付前清单。

其中大部分检查项是从真实事故反推的：图注符号与正文命名不一致、一般性结论的图里混进了具体数字、两幅图重复、点标签挤在一起。

## 如何使用

工作流以 Claude Code skill 的形式提供。把 `.claude/skills/` 下的目录复制到你的项目里即可被识别。

```bash
cp -r .claude/skills/* <你的项目>/.claude/skills/
```

**依赖**：配图功能需要 TeX 发行版（MiKTeX / TeX Live）提供 `pdflatex`、`pgfplots`，以及 `pdftoppm`。其余功能无外部依赖。

**注意**：`article_index.json` 的文章路径，以及 `euclids-gate-manage` / `euclids-gate-agenda` 中的索引路径，都是相对仓库根目录的相对路径；迁移到别的项目时，若目录布局不同需相应修改。
